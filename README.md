# Pro-Tack Hub

R&D goals, milestones, ideas, and change tracking for development & testing phases.

**Live:** https://cotycoots-tech.github.io/bb-development-hub/

## Features
- Projects (new development or existing machine mods)
- Goals, Milestones, Ideas, Change Log
- Mobile-first + Add to Home Screen (gear icon)
- Local storage + optional GitHub sync via Personal Access Token

## Setup GitHub Sync
1. Create a classic Personal Access Token with `repo` scope:  
   https://github.com/settings/tokens
2. Open the app → **Settings & Sync** → paste token → **Save Token**
3. Data is stored in `data.json` in this repository.

The token stays only in your browser’s localStorage.
