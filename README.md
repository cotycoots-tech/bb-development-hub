# BB Development Hub

R&D goals, milestones, ideas, and change tracking for development testing phases.

**Mobile-optimized** for iPhone.

## Live URL (after enabling Pages)

**https://cotycoots-tech.github.io/bb-development-hub/**

## Finish setup (takes ~2 minutes)

1. Download the complete application file from the conversation (or use the local `BB-Development-Hub.html`).
2. In this repository click **Add file → Upload files**.
3. Upload the HTML file and **rename it to `index.html`** (replace the current placeholder file).
4. Go to **Settings → Pages** (left sidebar).
5. Under **Source** select:
   - Deploy from a branch
   - Branch: `main`
   - Folder: `/ (root)`
6. Click **Save**.

Wait 30–90 seconds. The app will then be live at the URL above.

On iPhone: open the link in Safari → Share button → **Add to Home Screen** for an app-like icon.

## Features

- Projects (New Development / Existing Machine Modification)
- Goals with priority and target outcome
- Milestones
- Ideas capture
- Change Log (what changed, rationale, result)
- Local storage + JSON export/import for backup and sharing between the two users
- Fully responsive with iPhone-friendly navigation, safe-area support, and large touch targets
